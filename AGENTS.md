# Правила для агентов в этом репозитории

- Съёмка - отдельная система: ключей фабрики не брать, код фабрики не импортировать. Тест границы в `test/script.test.ts` это проверяет.
- О фабрике знать только её видимые выходы. Они перечислены в `src/contract.ts` и в `docs/demo/visible-outputs.md` в ai-factory; меняются вместе, с контрактным тестом фабрики.
- Итог шага ждать по связи с объектом дубля: ответ на сообщение шага, ключ задачи, номер PR, тег. Фраз фабрики в ожиданиях нет; `checkFilm` не пропускает сценарий с ними.
- Компоненты - только под лицензиями OSI; версии образов и пакетов закреплять точным тегом.
- Скрипты - POSIX sh; перед сохранением `make check` должен проходить.
- Код - TypeScript без сборки (Node стирает типы); перед сохранением `make test` должен проходить. Тесты - Vitest, стиль - Biome (`make fmt` форматирует).
- Секреты, токены, пароли и куки - только в `.state/`; в git, в аргументы команд и в логи не попадают.
- Запись во внешние системы повторяется только там, где повтор не даёт второго эффекта. Неясный итог записи сначала проверяется, потом повторяется.
